One-line: Compact status/category label using ReTrends semantic tones.

```jsx
<Badge tone="accent">Trending</Badge>
<Badge tone="positive">+12% YoY</Badge>
<Badge tone="navy" pill>RERA registered</Badge>
<Badge tone="navy" solid>New</Badge>
```

Tones: neutral · navy · accent · verified · trusted · positive · caution · negative. `solid` (neutral/navy/accent only) for filled chips like "New". `pill` for fully rounded. Tint tones are the default and read best on cards.
