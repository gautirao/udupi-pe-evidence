How states are reached. Discover V2 is a single-page app; each link opens the one design file at a URL hash (hash keys are reference-only, not a prescribed API). Navigation-level states (region, area, school, corridor, town, distance band) are genuinely restored by their hash. Overlay, within-results search and filter states are interaction-only — the prototype does not encode them in the URL, so their link opens the nearest base state and the card shows the exact interaction needed to reach the documented state. The app root carries data-design-screen="<state id>" and major components carry data-design-component matching VISUAL_RULES.md. The build is Bangalore-only; other cities are coming-soon placeholders.
