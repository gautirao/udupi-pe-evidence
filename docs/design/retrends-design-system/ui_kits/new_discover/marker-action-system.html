Discover map — three-marker action system

Every map marker is one connected component — an identity half flush against an attached action footer, one shared shell/shadow/border, one centred tail, one click/tap/keyboard target. Three variants share this shell but are never told apart by colour alone: each pairs a distinct body treatment with a distinct footer treatment, so the construction itself signals the behaviour.

ExploreDark navy identity + a solid accent footer in white. Enters a real Direction/Local Destination — updates node, breadcrumb, camera. The loud, two-tone card signals a real move into the hierarchy.
Zoom inLight cream (schools: lavender) identity + a white footer in accent text. Two-or-more destinations temporarily combined because every marker can't fit. Only pans/zooms — never touches node or breadcrumb.
View homes / View schoolsSame vertical card as Explore/Zoom: white identity (icon, area name, hero listing/school count, a secondary count when known) stacked above a solid dark footer in white — the inverse of Explore. Represents one real AREA leaf; the count lives in the identity section, never in the action label.
