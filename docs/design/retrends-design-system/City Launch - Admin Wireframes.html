City Launch — a four-step launch wizard

Low-fidelity wireframes + component hierarchy for the internal, admin-only workflow that takes a city live. Framed as one guided wizard — Select → Prepare → Preview & validate → Launch — so launching a city feels like a repeatable operational checklist, not a set of loose admin screens. It reuses the production Discover experience whole; it is not a GIS editor and never touches live data.

Reuses Discover / DS component New admin-only surface Read-only · safe Prepares city (sandbox writes) Guarded / irreversible ✎ Low-fi — structure & flow, not final visuals

Timestamps + current step. Each step shows start→end and duration; the running one is amber-striped with a live bar. No dashboards or charts — just the sequence, so the operator reads it at a glance.

Gated on validation. The launch action is disabled until all four step-3 checkpoints pass. Their timestamps + operator are carried here as the audit trail — the wizard remembers what was checked.
Two locks, not one. Disabled-until-complete and type-to-confirm. A city cannot be launched by a stray click; this is the only screen in the whole feature that promotes a revision to production.
Locked state (not shown). If a checkpoint is unmet the summary shows the gap, the confirm field is disabled, and a link sends the operator back to step 3 to finish validating.
SECURITY BOUNDARIES

Where the boundaries are

The whole wizard sits behind an admin-only guard. Within it, only step 2 does work, the preview only reads, and no step can touch or accidentally launch production Discover — except the final, doubly-confirmed launch.

Outer guard. Every route (/admin/cities/*) is wrapped in an AdminGuard. Non-admins never see the nav item, the routes, or the API. The 🔒 lock pill in each screen’s chrome marks the boundary.
Two data worlds, one crossing. Prepare + preview operate on an isolated sandbox draft revision, physically separate from live Discover. Step 4’s launch is the single, deliberate act that promotes a validated revision to production — nothing else crosses that line.
