One-line: ReTrends Lucide icon renderer — inherits `currentColor`, used inside buttons, badges and cards.

```jsx
<Icon name="map-pin" size={18} />
<Icon name="trending-up" size={16} color="var(--positive)" />
```

Icons available: map-pin, search, trending-up/down, shield-check, shield, file-check, bed, bath, maximize, calendar, heart, star, arrow-right, chevron-down, check, x, sliders-horizontal, building. Default size 20, stroke 2. For production use lucide-react directly; this is a self-contained subset.
