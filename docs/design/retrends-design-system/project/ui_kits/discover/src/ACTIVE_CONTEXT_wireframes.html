Discover · design handoff

Active context & a count you can trust

Desktop wireframes for the Discover active-context system: scope stays in the breadcrumb, filters and search become clearable chips, and the result count always names its scope and shows M of N when anything is filtering it — so a filtered zero never reads as "no properties in the city."

Full spec, tables and engineering handoff: ACTIVE_CONTEXT_AND_COUNT_BADGE_DESIGN.md. Mobile is out of scope.
