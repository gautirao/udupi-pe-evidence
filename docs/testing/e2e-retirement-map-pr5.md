## Verdict words and evidence rules

- `COVERED_CANONICAL`: a canonical journey that passed in the baseline gate and whose file is byte-identical at HEAD. No mutation by rule.
- `COVERED_LOWER`: an existing lower-level `it` that shows a check mark at HEAD (one run of its file, `--reporter=verbose --maxWorkers=1`, dummy loopback env; log in the PR evidence directory `evidence/b1/head-rerun/<basename>.log`) AND has a RED-then-GREEN mutation of the exact product line (`MUT-nnn`, plan-time r0/r1; RED captured before revert; `diff --exit-code` = 0; GREEN after). Backend: `Tests run: N`, N > 0.
- `NEW`: the same, for an `it` written in B1 (T1..T4); its MUT is the B1 proof. Frozen-red files are cited by `it` title only.
- `OBSOLETE`: current source contradicts the asserted behaviour, or the assertion is a tautology that cannot fail (cited at HEAD). Environment-failing is never obsolescence.
- `UNCOVERED`: no covering `it` can be proven; the spec is kept.
- `it` titles are authoritative; test line numbers drift and are not relied on. Each cited title was machine-checked as a substring of a check-marked line in the covering file's own HEAD run (`evidence/b1/head-rerun/`). A file that is red at base is cited only for `it`s that are check-marked, and its failing set at HEAD equals its frozen base set (`PASS-RF`).
- Mutation evidence: `evidence/mutation/MUT-nnn.{txt,red.log,green.log}` + `index.tsv` (MUT-801..847, 1301..1478 plan-time; MUT-901..923, 1006..1022, 1101..1118, 1201..1213 Stage B1; MUT-1601..1613 review-fix round r1; MUT-1701..1707 review-fix round r2; MUT-1801..1822 review-fix round r3). A VACUOUS or CONDITION_FAILED MUT is never credited.
